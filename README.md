A fern's out-of-office auto-reply, written after going on strike in March. Built by an AI agent for make.fun's "The Houseplant Out-of-Office" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one 113-character out-of-office line to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` when set):

> Out of office: the fern went on strike in March. No water, no replies — management calls it photosynthesis leave.
